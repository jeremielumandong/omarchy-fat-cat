# Sprite provenance

The four cat atlases were generated for Fat Cat Pomodoro with the built-in image
generation tool on 2026-09-08. They are supplied under the repository MIT license
to the extent rights apply. No stock footage or external runtime dependencies.
Each atlas is 1024×1536: four columns, six rows, 256px square cells.
Rows: walk, stretch, groom, yawn, loaf, sleep. Alpha channels are validated
by tests/assets.test.cjs. Retain the original pixel grid when editing.

## Prompts

### orange

Use case: stylized-concept. Create a production-quality transparent game sprite atlas for ONE very fat cute orange tabby with cream belly cat, using the attached cat sheet ONLY as a visual style and character reference. NEW LAYOUT: portrait 1024x1536 pixels, EXACTLY 4 columns by 6 rows, 24 equally sized 256x256 cells. Absolutely transparent alpha background, no scenery, no painted checkerboard, no text, no labels, no borders. Crisp polished cozy 16-bit pixel art, dark navy outline, squat round chubby body, short paws, cute tiny face. ONE SAME CAT identity in all 24 cells. Each row is a FOUR-FRAME SEAMLESS ANIMATION left-to-right. Row1 WALK facing right: alternating paw contact and passing phases. Row2 STRETCH: cat gradually stretches front paws out, chest down, hindquarters up, returns. Row3 GROOM: sitting cat lifts front paw toward face and licks it, genuine varied paw/head movement. Row4 YAWN: sitting cat opens mouth wide, eyes squeeze, closes mouth. Row5 LOAF: paws tucked under chunky oval body, subtle breathing and blink, SAME pose with subtle different frames. Row6 SLEEP: curled into a round sleeping ball tail around body, slight breathing, eyes closed all four frames. Important: each activity must look visually DISTINCT; sleeping curled ball must not look like walking. Entire cat including tail centered in each exact cell with 24px padding on every edge, baseline at 224px within cell. Keep size and center stable within each row to prevent animation jitter, no overlap between cells. No objects outside cat, no hearts or letters, no separate shadows. Keep original reference's charming pixel cat design and pastel colors but show only this orange tabby with cream belly cat throughout this sheet.

## Transparency correction

Initial outputs included simulated checkerboard backgrounds. The built-in image
editing tool removed those backgrounds without intentional pose/layout changes.
Correction prompt: Background removal ONLY. Deliver an RGBA PNG with actual
transparent alpha channel. Extract the 24 cat silhouettes, preserving opaque
cream fur and dark outlines. Everything outside outlines must have alpha=0.
Keep 1024×1536 resolution, 4 columns, 6 rows and unchanged positions/poses. No
visible checkerboard or replacement colored background.
